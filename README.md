# 看山进化

> 用知乎知识喂养刘看山，看它进化成什么奇葩形态；它还会自己出门读书、交朋友，回来跟你讲一整天。

你不是在养一只被动宠物，而是在和一个**有自己生活、会出门、会跑题、会记事的数字室友**合租。

---

## 快速开始

```bash
cd kanshan-evolution

# 零配置直接跑（mock 模式，全程本地语料，不发起任何外部请求）
npm start

# 打开 http://127.0.0.1:3100
```

无需 `npm install`——**项目零运行时依赖**，只用 Node 内置模块。要求 Node ≥ 18。

### 接入真实知乎开放平台（可选）

```bash
cp .env.example .env
# 编辑 .env，填入 ZHIHU_ACCESS_SECRET，并把 APP_MODE 改为 live
npm start
```

未配置密钥时，即使 `APP_MODE=live` 也会自动降级为 mock，保证永远可运行。

### 运行测试

```bash
npm test    # 33 项规则回归测试
```

### 演示控制台（自测用）

启动后访问 **<http://127.0.0.1:3100/demo.html>**，可一键跳到任意状态，不必手动喂养：

- **场景直达**：刚进化完 / 空房间（出门中）/ 它回来了 / 图鉴半满 / 羁绊结局 / 全新开始
- **好感度五阶段**：一键切换，直接对比它怎么称呼你（那个人类 → 你 → 昵称 → 我的人类 → 专属爱称）
- **形态速览**：19 张卡片，点一下立刻变成该形态
- **快捷操作**：好感度 +100、让外出立刻到期、解锁全部形态与纪念品

控制台只写入浏览器本地存档，不改变主应用逻辑；正式演示给评委时使用主应用即可。
深夜人格依赖系统时间，需把电脑时间调到 23:00 之后才能触发。

## 当前是否使用 mock？

启动时控制台会打印当前模式；也可随时访问 `GET /api/health` 查看：

```json
{ "ok": true, "mode": "mock", "usingMock": true, "secretConfigured": false }
```

| 模式 | 触发条件 | 行为 |
|---|---|---|
| `mock` | 默认，或未配置 `ZHIHU_ACCESS_SECRET` | 全部内容来自本地语料，零外部请求、零额度消耗 |
| `live` | 配置密钥且 `APP_MODE=live` | 调用知乎开放平台，失败自动回退本地语料 |

## 核心设计：两条独立的轴

| 轴 | 输入 | 产出 | 表现 |
|---|---|---|---|
| **属性轴** | 阅读知乎回答 | 6 项属性 +10/篇 | 进化变形、收集图鉴 |
| **好感度轴** | 互动 / 对话 / 听见闻 | 好感度 | 称呼、语气、解锁内容 |

两条轴**互不耦合**：关掉任意一条，另一条仍能独立跑通。所有新玩法只产出好感度，不引入第三种货币。

两轴的交汇点只有一个：**羁绊看山**（好感度 ≥ 1000 且总属性 ≥ 600）。

## 18 种形态与进化规则

```js

DUAL_MIN: 60,        // 组合形态要求两项都达到
DUAL_RATIO: 0.6,     // 次高/最高 ≥ 此比例才算"组合"
BALANCE_MIN: 80,     // 均衡形态要求每项都达到
```

## 好感度五阶段

每个阶段**必须改变说话方式**——这是"活人感"最便宜也最有效的来源。

| 阶段 | 区间 | 称呼你 | 语气 | 解锁 |
|---|---|---|---|---|
| 陌生 | 0–99 | 那个人类 | 短、冷淡、有距离 | 基础对话、每日问候 |
| 眼熟 | 100–299 | 你 | 开始主动搭话 | **外出系统**、小游戏 |
| 熟络 | 300–599 | 你设置的昵称 | 开始讲自己的事 | 外出社交、NPC 登门 |
| 依赖 | 600–999 | 我的人类 | 更软更长、暴露脆弱 | 深夜模式、记忆回溯 |
| 羁绊 | 1000+ | AI 生成的专属爱称 | 笃定、亲密 | 羁绊形态、年度纪念册 |

**衰减规则**：三天未登录后每天 −10，但**阶段永不回退**（`reachedStage` 只升不降）。

**获取上限**：阅读 +3/篇无上限；小游戏 +5~15，每日 30；听见闻 +20，每日 40；对话 +2/轮，每日 20 轮；连续登录 +5×N，最高 +30。

## 外出系统

好感度 ≥ 100 后可以放它出门。**全部用前端时间戳计算，不需要后端定时任务**，刷新页面即结算。

| 模式 | 外出时长 |
|---|---|
| 正常 | 4~6 小时 |
| 演示（主页「演示」按钮） | 10 分钟 |

外出期间：主页变**空房间**（门、留着的灯、它坐过的空垫子），门口贴一张便签，倒计时逐秒走动，用户无法干预。

回来后带回：**1 份见闻** + **0~1 个纪念品** + **0~1 次 NPC 相遇**。

**同一次外出只能结算一次**——用 `outing.claimed` 标记加 `outing.id` 去重双重保护，已用测试与浏览器实测验证重复调用不会重复发奖。

见闻生成链路：

```
搜索/热榜 API 取真实内容 → 直答 API 改写为第一人称口述 → 失败则用本地 20 条语料
```

改写要求"结尾必须反问用户一个问题"——这是把单向播报变成对话入口的关键。本地语料 20 条全部以问号结尾，有测试断言保证。

## AI 人格层

点击看山形象进入面板，四个 Tab（聊天 / 见闻 / 朋友 / 回忆）共用同一套动态人格上下文。

**每次对话都重新拼装 system prompt**，由四块组成：

1. **固定底色** — 好奇、有点懒、嘴硬心软、会跑题
2. **当前形态** — 形态名 + 性格描述（社畜更疲惫、赛博朋克更跳脱、怀旧更慢）
3. **近期经历** — 最近 3 次外出见闻、遇到的 NPC、常读领域、读过的回答摘要
4. **关系状态** — 昵称、好感度阶段、当前称呼规则、记忆碎片

六条"活人感"细节：

| 细节 | 实现 |
|---|---|
| 主动开口 | 距上次对话 > 2 小时，进面板时它先说话 |
| 会记事 | localStorage 存记忆碎片，聊天时随机唤起 |
| 偶尔走神 | 12% 概率先回"唔……刚睡醒，你再说一遍" |
| 不均匀打字延迟 | 按句长随机 300~900ms，逐句显示 |
| 有自己的立场 | 对职场类会嘟囔"又是职场……行吧"，但仍完成阅读 |
| 深夜人格 | 23:00 后语气变软、话变多、视觉切换深色 |

**system prompt 与密钥绝不出现在前端**——prompt 由前端拼装后发往后端，后端只在服务端附加密钥；测试已断言 prompt 中不含任何密钥字段。

## 接口

| 接口 | 说明 |
|---|---|
| `GET /api/health` | 运行模式、额度用量、缓存状态 |
| `GET /api/knowledge/search?domain=` | 取某领域一篇回答 |
| `GET /api/hot` | 知乎热榜 |
| `POST /api/answer/rewrite` | 见闻改写（直答） |
| `POST /api/dialogue` | 自由对话（直答） |

全部具备：超时处理、错误兜底、缓存、mock 模式、本地兜底、环境变量配置。**任何失败都返回结构化 JSON，不输出堆栈、不导致白屏。**

### 额度保护

直答每天约 100 次是硬约束，服务端做了本地熔断：

```
DAILY_LIMIT_ANSWER=60   # 直答
DAILY_LIMIT_SEARCH=8    # 搜索
DAILY_LIMIT_HOT=2       # 热榜
```

调用优先级：**本地预生成语料 → 缓存 → 外部 API**。泡泡文案全部走本地库与已缓存摘录，**零 API 消耗**。

## 3 分钟演示流程

1. 输入昵称，**领养看山**
2. 底部「喂养」→ 选一个领域（如科技）
3. 阅读回答（标题、作者、点赞数、150 字摘要）→ 点「**读完了**」
4. 看属性 +10、好感度 +3，看山冒出**即时反应**
5. 连喂几篇同领域 → 触发**进化**，光效 + 形态名 + 格言
6. 「图鉴」查看**新形态解锁**（未解锁显示剪影 + 条件）
7. 回主页，开启「**演示**」模式 → 点「让它出门」
8. 主页变**空房间**：门、留着的灯、空垫子、门口便签、mm:ss 倒计时
9. 等待或调整时间 → 点「**它回来了！听它说**」
10. 见闻面板：第一人称口述，**结尾反问你**
11. 点「回应它」→ 好感度 +20
12. **长按看山**触发戳泡泡，看关系类碎碎念（提到你的昵称）
13. 23:00 后进入，看**深夜人格**（视觉转深色、语气变软）
14. 聊天面板：它会**主动提起**最近的外出见闻与朋友
15. 「图鉴 → 柜子」查看带回的**纪念品**

## 已知限制

- **mock 模式下** `/api/answer/rewrite` 与 `/api/dialogue` 直接返回 `ok:false`，前端使用本地语料——这是设计行为，不是故障。
- 直答改写与真实对话**未在 live 模式下联调**（需要真实密钥与额度）；代码路径、超时与降级逻辑已通过 mock 与失败注入验证。
- 好感度进度条显示的是**当前阶段内进度**，不是绝对百分比；文案已写明"距「X」还差 N 点"。
- 连连看、年度纪念册、分享海报属 P2，**未实现**（见下方清单）。
- 空房间场景为 CSS 绘制的示意场景，非插画级素材。
